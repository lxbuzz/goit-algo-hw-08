# Консольний бот-помічник Address Book + Birtday (CLI Address Book Bot) — ДЗ №7

Цей проєкт є розширенням персонального помічника на базі ООП. Він об'єднує попередні напрацювання в єдиний функціональний консольний застосунок для керування контактами, телефонними номерами та відстеження найближчих днів народження.

## 📋 Основні можливості та архітектура

Проєкт побудований на базі модульної структури класів, які успадковують базову логіку та забезпечують сувору валідацію даних:

### 1. Архітектура класів (`address_book/`)
- **`Field`**: Базовий клас для полів запису із загальною логікою.
- **`Name`**: Поле для зберігання імені контакту (обов'язкове).
- **`Phone`**: Поле для зберігання номера телефону. Містить валідацію: номер має складатися **рівно з 10 цифр**.
- **`Birthday`**: Нове поле для зберігання дати народження. Містить валідацію формату **`DD.MM.YYYY`** та автоматичне перетворення у формат дати.
- **`Record`**: Клас для зберігання інформації про один контакт, включаючи ім'я, динамічний список телефонів та одне необов'язкове поле дня народження. Підтримує методи додавання, видалення, редагування телефонів та додавання дати народження.
- **`AddressBook`**: Клас для керування всіма записами (наслідується від `UserDict`). Містить фінальний алгоритм пошуку іменинників на найближчий тиждень.

### 2. Логіка привітань (`get_upcoming_birthdays`)
Метод автоматично аналізує всі контакти в адресній книзі та повертає список тих, у кого день народження припадає на найближчі **7 днів**, включаючи поточний день. 
- **Перенесення на робочі дні**: Якщо день народження припадає на вихідні (суботу або неділю), дата привітання автоматично переноситься на наступний понеділок.
- **Обробка високосних років**: Коректно обробляється дата 29 лютого для невисокосних років (перенесення на 28 лютого).

### 3. Надійність та обробка помилок
Усі команди та користувацький ввід проходять через декоратор `@input_error`, який перехоплює можливі винятки (`ValueError`, `IndexError`, `KeyError`) та виводить зрозумілі й інформативні підказки користувачеві замість аварійного завершення програми.

## 💻 Список команд бота

Бот підтримує інтерактивний CLI-інтерфейс із наступними командами:

| Команда | Аргументи | Опис | Приклад використання |
| :--- | :--- | :--- | :--- |
| **`hello`** | *без аргументів* | Отримати привітне вітання від бота. | `hello` |
| **`add`** | `[ім'я] [телефон]` | Додати новий контакт або додати новий телефон до існуючого контакту. | `add John 1234567890` |
| **`change`** | `[ім'я] [старий_тел] [новий_тел]` | Змінити існуючий номер телефону для вказаного контакту. | `change John 1234567890 5555555555` |
| **`phone`** | `[ім'я]` | Показати всі телефонні номери для вказаного контакту. | `phone John` |
| **`all`** | *без аргументів* | Вивести всі збережені контакти в адресній книзі. | `all` |
| **`add-birthday`** | `[ім'я] [дата]` | Додати або оновити дату народження контакту у форматі `DD.MM.YYYY`. | `add-birthday John 25.05.1995` |
| **`show-birthday`** | `[ім'я]` | Показати дату народження вказаного контакту. | `show-birthday John` |
| **`birthdays`** | *без аргументів* | Показати список людей, яких потрібно привітати на найближчому тижні. | `birthdays` |
| **`close`** або **`exit`** | *без аргументів* | Коректно завершити роботу програми із збереженням стану. | `exit` |
