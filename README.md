# Консольний бот-помічник Address Book + Збереження даних (CLI Address Book Bot) — ДЗ №8

Цей проєкт є розширенням персонального помічника на базі ООП. Він об'єднує попередні напрацювання в єдиний функціональний консольний застосунок для керування контактами, телефонними номерами, відстеженням найближчих днів народження, а тепер — **із функцією постійного збереження даних**.

## 📋 Основні можливості та архітектура

Проєкт побудований на базі модульної структури класів із додаванням протоколу серіалізації:

### 1. Збереження стану (Pickle)
- Дані адресної книги більше не втрачаються після закриття програми.
- Застосунок використовує модуль `pickle` для збереження всього об'єкта `AddressBook` у файл `addressbook.pkl` під час виходу (команди `exit` або `close`).
- Під час нового запуску програма автоматично зчитує дані з файлу `addressbook.pkl` та відновлює попередній стан.

### 2. Архітектура класів (`address_book/`)
- **`Field`**: Базовий клас для полів запису із загальною логікою.
- **`Name`**: Поле для зберігання імені контакту.
- **`Phone`**: Поле телефону (валідація: рівно 10 цифр).
- **`Birthday`**: Поле дати народження (валідація: `DD.MM.YYYY`).
- **`Record`**: Клас для зберігання інформації про контакт (ім'я, телефони, день народження).
- **`AddressBook`**: Клас для керування всіма записами. Містить логіку пошуку іменинників на найближчий тиждень.

### 3. Логіка привітань (`get_upcoming_birthdays`)
Аналізує всі контакти і повертає список тих, у кого день народження припадає на найближчі **7 днів**. Вихідні автоматично переносяться на понеділок.

## 💻 Список команд бота

| Команда | Аргументи | Опис | Приклад використання |
| :--- | :--- | :--- | :--- |
| **`hello`** | *без аргументів* | Отримати привітне вітання від бота. | `hello` |
| **`add`** | `[ім'я] [телефон]` | Додати новий контакт або телефон. | `add John 1234567890` |
| **`change`** | `[ім'я] [старий_тел] [новий_тел]` | Змінити номер телефону. | `change John 1234567890 5555555555` |
| **`phone`** | `[ім'я]` | Показати всі телефонні номери контакту. | `phone John` |
| **`all`** | *без аргументів* | Вивести всі збережені контакти. | `all` |
| **`add-birthday`** | `[ім'я] [дата]` | Додати дату народження (`DD.MM.YYYY`). | `add-birthday John 25.05.1995` |
| **`show-birthday`** | `[ім'я]` | Показати дату народження контакту. | `show-birthday John` |
| **`birthdays`** | *без аргументів* | Список днів народження на тиждень. | `birthdays` |
| **`close` / `exit`** | *без аргументів* | Завершити роботу **та зберегти дані**. | `exit` |
